1. Project OverviewThis project is a desktop Poker Game Application built using JavaFX for the graphical user interface (GUI). The application simulates a high-card poker tracking variant where two players draw five cards sequentially from a shuffled standard 52-card deck. Once all cards are drawn, the application compares the highest card value in each player's hand to determine the winner.2. System ArchitectureThe application is structured inside a self-contained, single-file architecture (PokerGame.java) for easy compilation and evaluation. It consists of three primary layers:Data Layer (Card, Deck, Player Classes): Static nested components that model standard card decks. The Card class tracks suit, rank, and numeric value. The Deck handles shuffling and card removal, while the Player class stores the drawn hand and calculates the highest card score.Presentation Layer (JavaFX GUI): A clean interface split into two vertical columns using an HBox layout to track hands for both "Player 1" and "Player 2" independently.Control Layer (Action Handling): Manages real-time application states via step-by-step conditional switches, matching button text updates to the active player's draw index (cardCount).3. Key Technical FeaturesA. Object-Oriented Game LogicThe game strictly follows Object-Oriented Programming (OOP) principles. The card generation is automated at initialization using nested loops inside the Deck constructor, mapping ranks to suits and cleanly converting face card identities into comparative structural values ($Jack = 11$, $Ace = 14$).B. Dynamic Step-by-Step UI FeedbackInstead of dealing all cards at once, the application implements a structural step-by-step draw workflow. By tracking a cardCount index (0–4 for Player 1, 5–9 for Player 2), the system dynamically updates button text labels in real time, shifting execution focus smoothly across players before disabling inputs during final result rendering.C. Modern Stream API EvaluationThe evaluation of the winning hand utilizes Java's modern Stream 
This efficiently extracts, maps, and calculates maximum integer hand values concisely without requiring manual, multi-line sorting algorithms.4. ConclusionThe PokerGame application delivers a fully functional, stable, and clean object-oriented card simulation. By utilizing structural JavaFX layout styling alongside modern Stream pipelines, the application offers an efficient architecture well-suited for an academic desktop application submission.
